# Stockfish.js

Download the engine from:
https://github.com/nmrugg/stockfish.js

Recommended for browsers: **lite single-threaded**
- stockfish-*-lite-single.js
- corresponding .wasm file

Place the files in this folder and update the path in js/stockfish-engine.js or js/config.js if needed.

The site will fall back to random legal moves if Stockfish is not present.
